# สรุปคอร์ส Canva พื้นฐาน และ Prompt

เว็บไซต์รวมสรุปเนื้อหา **หลังการอบรม** สำหรับนักเรียน ม.3 และ ม.6 ที่เรียนคอร์ส
"Canva พื้นฐาน และ Prompt" ไปแล้ว ให้กลับมาอ่านทบทวนประเด็นสำคัญ กิจกรรมในคาบ และสไลด์ที่ใช้สอนได้ทุกเมื่อ

> เว็บนี้ไม่ใช่เว็บขายคอร์สหรือหน้าประชาสัมพันธ์ และไม่ใช่เว็บทางการของคอร์ส

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173
npm run build    # สร้างไฟล์สำหรับขึ้นเว็บจริงในโฟลเดอร์ dist/
npm run preview  # ลองดูผลของ build ก่อนขึ้นจริง
```

## หน้าเนื้อหาแต่ละหัวข้อมีอะไรบ้าง

ชื่อหัวข้อ → คำโปรย → ตัวสลับ ม.3/ม.6 + ปุ่มปักหมุด → **ประเด็นสำคัญ** → **กิจกรรมในคาบ** → **สไลด์ Canva**
พร้อมสารบัญลอยด้านซ้าย (3 รายการตามหัวข้อหลัก) และปุ่มไปหัวข้อก่อนหน้า/ถัดไปที่คงระดับชั้นเดิม

## หน้าเว็บทั้งหมด

| เส้นทาง (URL) | หน้าอะไร |
| --- | --- |
| `/` | หน้าแรก — การ์ด 4 หัวข้อ + หัวข้อที่ปักหมุดไว้ |
| `/topic/:slug/:grade` | เนื้อหาของหัวข้อหนึ่ง ๆ (`grade` = `m3` หรือ `m6`) |
| `/instructors/m3` | ทีมพี่ผู้สอน ม.3 (4 คน) |
| `/instructors/m6` | ทีมพี่ผู้สอน ม.6 (4 คน) |

`slug` ของ 4 หัวข้อคือ `canva-basics`, `canva-ai`, `prompt-presentation`, `prompt-portfolio`
ถ้าใส่ `grade` ผิด เว็บจะพากลับไปที่ `m3` ให้เอง

## จะแก้เนื้อหาต้องแก้ที่ไหน

เนื้อหาทั้งหมดแยกออกจากหน้าตาเว็บแล้ว แก้แค่ 3 ไฟล์นี้พอ
ทุกช่องที่ยังเป็นข้อความตัวอย่างจะมีคอมเมนต์ `// TODO:` กำกับไว้

### 1. `src/data/topics.ts` — เนื้อหา 4 หัวข้อ × 2 ระดับชั้น (8 ชุด)

แต่ละหัวข้อมี `contentByGrade.m3` และ `contentByGrade.m6` แยกกันคนละชุด
เพราะ ม.3 กับ ม.6 เรียนหัวข้อชื่อเดียวกันแต่เนื้อหาจริงคนละชุด แต่ละชุดมี:

- `summary` — คำโปรยสั้น ๆ (แสดงต่อจากชื่อหัวข้อ ไม่มีป้ายกำกับ)
- `content[]` — ประเด็นสำคัญ
- `workshop` — กิจกรรมที่ทำในคาบ
- `canvaEmbedUrl` — สไลด์ Canva ของชุดนี้
- `instructorId` — พี่ผู้สอนที่รับผิดชอบ (ต้องตรงกับ `id` ใน `instructors.ts`)

### 2. `src/data/instructors.ts` — พี่ผู้สอน 8 คน

ชื่อและรูปครบทั้ง 8 คนแล้ว เหลือแค่ `bio` ที่ยังเป็นข้อความตั้งต้น รอกรอกของจริง

**เปลี่ยนรูปพี่ผู้สอน**: วางไฟล์ทับที่ `src/assets/instructors/<id>.jpg`
(เช่น `m6-topic2.jpg`) ได้เลย ถ้าเพิ่มคนใหม่ให้ `import` เข้ามาที่หัวไฟล์ `instructors.ts`
แล้วใส่ตัวแปรนั้นในช่อง `photoUrl`

ไฟล์รูปต้นฉบับความละเอียดเต็มเก็บไว้ที่ `img-m3/` และ `img-m6/`
ส่วนที่อยู่ใน `src/assets/instructors/` เป็นสำเนาที่ย่อขนาดให้เหมาะกับเว็บแล้ว

### 3. `src/data/links.ts` — ลิงก์ Padlet คลัง Prompt Template ของแต่ละระดับชั้น

## เรื่องสไลด์ Canva

`CANVA_DECK_URL` ใน `topics.ts` เก็บลิงก์ `canva.link` ที่ได้รับมา
ลิงก์เหล่านั้นเป็นลิงก์แบบ **เปิดเพื่อแก้ไข** (`/edit`) ซึ่ง Canva ไม่ยอมให้ฝังใน iframe ของเว็บอื่น

ด้านล่างจึงมีตาราง `CANVA_RESOLVED` ที่จับคู่ลิงก์นั้นกับลิงก์ **ดูอย่างเดียว** ของสไลด์ชุดเดียวกัน
แล้วให้ทั้ง iframe และปุ่ม "เปิดสไลด์ในแท็บใหม่" ใช้ลิงก์ดูอย่างเดียวแทน
นักเรียนจะได้ไม่เผลอเข้าไปแก้สไลด์ต้นฉบับของพี่ผู้สอน

ถ้าเปลี่ยนไปใช้สไลด์ชุดใหม่ ให้แก้ทั้ง `CANVA_DECK_URL` และเพิ่มคู่ลิงก์ใน `CANVA_RESOLVED` ด้วย

## ปุ่มลัดบน Navbar

ท้ายแถบเมนูมีปุ่มทึบสีธีมสองปุ่ม แต่ละปุ่มกางเมนูย่อยเลือก ม.3 / ม.6 แล้วเปิดแท็บใหม่

| ปุ่ม | ไปที่ไหน | แก้ลิงก์ได้ที่ |
| --- | --- | --- |
| **Padlet** | Padlet คลัง Prompt Template ของแต่ละระดับชั้น | `PADLET_URL` ใน `links.ts` |
| **Canva** | สไลด์ Canva รวมทั้งชุดของแต่ละระดับชั้น | `CANVA_DECK_URL` ใน `topics.ts` |

## เอาขึ้นเว็บจริง

เว็บนี้เป็น single-page app ที่อ่าน URL ตรง ๆ ได้ (เช่นเปิด `/topic/canva-basics/m6` แล้ว refresh)
เซิร์ฟเวอร์จึงต้องส่ง `index.html` กลับมาสำหรับทุกเส้นทาง — ในโปรเจกต์นี้เตรียมไว้ให้แล้ว:

- Netlify / Cloudflare Pages → `public/_redirects`
- Vercel → `vercel.json`
